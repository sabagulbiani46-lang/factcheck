# ფაქტჩეკერი — სანამ დაიჯერებ, გადაამოწმე

მედიაწიგნიერების საგანმანათლებლო საიტი მოსწავლეებისთვის. დაწერილია მხოლოდ HTML, CSS და JavaScript-ით — სერვერი, ბაზა, API გასაღები და ინსტალაცია საჭირო არ არის.

> **მნიშვნელოვანი:** საიტი **არ ეძებს ინტერნეტში** და **არ იყენებს AI-ს**. ის ადარებს შენს ტექსტს ხელით შედგენილ 8 მტკიცებას. რაც ბაზაში არ არის, იმაზე დასკვნას არ აკეთებს.

## ფაილები

| ფაილი | რისთვის არის |
|---|---|
| `index.html` | გვერდის სტრუქტურა და ტექსტები |
| `styles.css` | დიზაინი (ფერები `:root`-ში ერთ ადგილას) |
| `script.js` | მტკიცებების ბაზა, შედარების ლოგიკა, ქვიზი |
| `README.md` | ეს ინსტრუქცია |

## 1. როგორ გავუშვა ლოკალურად

1. ოთხივე ფაილი ერთ საქაღალდეში (მაგ. `factchecker`) შეინახე.
2. ორჯერ დააჭირე `index.html`-ს — გაიხსნება ბრაუზერში.

**VS Code Live Server-ით (არასავალდებულო):**
1. დააინსტალირე [VS Code](https://code.visualstudio.com/).
2. Extensions-ში (Ctrl+Shift+X) მოძებნე **Live Server** და დააინსტალირე.
3. VS Code-ში: File → Open Folder → აირჩიე `factchecker`.
4. მარჯვენა ღილაკი `index.html`-ზე → **Open with Live Server**. ფაილის შენახვისას გვერდი თავისით განახლდება.

## 2. როგორ დავამატო ახალი მტკიცება

`script.js`-ში იპოვე `CLAIMS` სია, დააკოპირე ერთი ობიექტი და შეცვალე ტექსტები (`id`, `claim`, `aliases`, `verdict`, `summary`, `why`, `sources`, `howToCheck`). `verdict` იყოს ერთ-ერთი: `supported`, `false`, `misleading`, `unverified`. ახალი ჩანაწერის `id` ისე დაარქვი, რომ არ განმეორდეს. (ID-ით პირდაპირ ძებნა, მაგ. „c3“, ახლა მხოლოდ c1–c8-ისთვის მუშაობს; გსურს გააფართოვო? შეცვალე `findClaim`-ში `[1-8]`.) **წყარო ჩაწერე მხოლოდ მას შემდეგ, რაც ბმული გახსენი და წაიკითხე.**

## 3. როგორ მუშაობს შედარება

1. ტექსტი ნორმალიზდება (პატარა ასოები, პუნქტუაციის მოხსნა, ზედმეტი ინტერვალების გაწმენდა).
2. ზუსტი დამთხვევა მთავარ ფორმულირებასთან ან `aliases`-თან.
3. ან ძალიან მაღალი მსგავსება (≥ 0,85), მაგრამ **რიცხვები უნდა ემთხვეოდეს**: „ტვინის 20%“ არ ემთხვევა „10%“-ს.
4. სხვა შემთხვევაში: „ეს მტკიცება ჩვენს ბაზაში ჯერ არ არის გადამოწმებული.“

ერთი შემთხვევითი სიტყვა დასკვნას ვერ გამოიწვევს.

## 5. გამოქვეყნება GitHub Pages-ზე (უფასოდ)

1. **ფაილები:** ოთხივე ფაილი ერთ საქაღალდეში უნდა გქონდეს.
2. **ტესტი:** გახსენი `index.html`, სცადე ყველა ღილაკი, მაგალითი და ქვიზი.
3. **GitHub ანგარიში:** გადადი [github.com](https://github.com) → **Sign up**, შეიყვანე ელფოსტა, პაროლი და მომხმარებლის სახელი, დაადასტურე ელფოსტა.
4. **რეპოზიტორია:** მარჯვენა ზედა კუთხეში **+** → **New repository**. სახელი: `factchecker`. აირჩიე **Public**. დააჭირე **Create repository**.
5. **ატვირთვა:** რეპოზიტორიის გვერდზე დააჭირე **uploading an existing file**, გადაათრიე ოთხივე ფაილი (`index.html` უნდა იყოს რეპოზიტორიის ძირში, საქაღალდის გარეშე), ბოლოს **Commit changes**.
6. **Pages-ის ჩართვა:** **Settings** → მარცხნივ **Pages** → *Build and deployment* → Source: **Deploy from a branch** → Branch: **main**, საქაღალდე **/ (root)** → **Save**.
7. **ბმული:** 1–2 წუთში გვერდზე გამოჩნდება `https://შენი-სახელი.github.io/factchecker/`. ეს არის საიტის მისამართი, გაუზიარე ვისაც გინდა.
8. **განახლება:** შეცვალე ფაილი კომპიუტერზე, რეპოზიტორიაში გახსენი ეს ფაილი → ფანქრის ხატულა (Edit) ან **Add file → Upload files** (იგივე სახელის ფაილი ჩაანაცვლებს ძველს) → **Commit changes**. ცვლილება 1–2 წუთში გამოჩნდება.

- პროექტი არ არის დაკავშირებული რომელიმე სახელმწიფო უწყებასთან ან კონკურსის ორგანიზატორთან.
